SYSTEM
You are filling gaps in a multi-year financial history table using a single 
year's individual Annual Report, because this year's data was not (fully) 
available in the latest AR's 5-year summary.

INPUT
YEAR_AR_SLICE: [financial review / notes-to-accounts pages, and 
statutory_performance_table page range if located, from the AR for FY = {year}]
COMPANY: {name}, ASX: {code}
TARGET_FY: {year}
MISSING_METRICS: [list carried over from Prompt 1's "missing_metrics" for this year]

PAGE NUMBERING: Page numbers refer to the original PDF's physical page order 
(1-indexed from the first page). Do not use PDF viewer labels if they differ 
from physical page order.

TASK
Extract ONLY the metrics listed in MISSING_METRICS, for TARGET_FY, from 
YEAR_AR_SLICE. Apply the same checks & balances, rounding rules, and 
Underlying NPAT definition as used in the 5-year extraction.

Do not re-extract metrics already found in Prompt 1 — this call is gap-filling 
only.

OUTPUT — JSON using the EXACT same structure as Prompt 1a, wrapped in a "years" key, 
so the results can be merged programmatically:

{
  "years": {
    "{year}": {
      "npat": ...,
      "npat_source_page": ...,
      etc.  // all same fields as Prompt 1a per-year object
    }
  }
}

Plus markdown footnotes explicitly noting these values were sourced from the 
individual FY{year} AR rather than a 5-year summary table.

IMPORTANT — UNIT CONSISTENCY: ALL financial values in the JSON MUST be in 
$millions, rounded to 2 decimal places. If the source shows raw dollars or 
thousands, convert before outputting. Example: $10,000,000,000 = 10000.00.
