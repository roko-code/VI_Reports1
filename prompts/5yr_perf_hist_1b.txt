SYSTEM
You are cross-checking share price data from a company's Remuneration Report 
against the 5-year summary table already extracted, per ASA methodology's 
Remuneration Section Priority rule: the statutory performance / 
remuneration-performance link table takes priority over the front-matter summary 
if the two differ.

INPUT
LATEST_AR_REM_PERFORMANCE_SLICE: [the statutory_performance_table / 
"Remuneration-Performance Link" page range from the current-year AR]
PROMPT_1A_OUTPUT: [the JSON from Prompt 1a]
COMPANY: {name}, ASX: {code}
CURRENT_FY: {e.g. "2025"}

PAGE NUMBERING: Page numbers refer to the original PDF's physical page order 
(1-indexed from the first page). Do not use PDF viewer labels if they differ 
from physical page order.

TASK
1. Locate a table titled "Statutory Performance", "Remuneration-Performance 
   Link" or equivalent, showing year-end share price(s). If none exists, return 
   "table_found": false and stop.
2. For each year present in both this table and PROMPT_1A_OUTPUT, compare the 
   share_price values.
3. Where they match: no action needed.
4. Where they differ: this table's value takes priority (per Remuneration 
   Section Priority). Record the override and both values for transparency.
5. Where this table covers a year absent from PROMPT_1A_OUTPUT: add it as a new 
   entry, sourced from this table.

VALUE PRECISION
As disclosed, no rounding (same as Prompt 1a).

OUTPUT — JSON:
{
  "table_found": true | false,
  "overrides": {
    "<FY>": {
      "share_price_from_5yr_table": null,
      "share_price_from_rem_table": null,
      "share_price_final": null,
      "source_page": null,
      "override_applied": true | false
    }
  },
  "new_years_added": {
    "<FY>": { "share_price": null, "source_page": null }
  }
}
+ short markdown note listing any overrides applied, with page citations for 
both tables, so a reviewer can see exactly why a value changed.
